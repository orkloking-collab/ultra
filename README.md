# 🌈 Pixora — Colorful Videos & Unique Images

Pixora is a bright, colorful, mobile-friendly social-style website for videos and unique images — built completely from scratch (no templates, no copies).

## ✨ Features

- ⭐ **Featured Slider** — auto-sliding showcase of trending posts
- 📚 **26+ Posts** — videos (YouTube embed) & unique images, each with title, description and tags
- 🎮 **Categories** — Gaming, Anime, News, Music, Movies, Sports, Tech, Travel, Food, Art, City, Nature, Pets & Fun
- 💡 **Visitor Suggestions** — visitors submit videos/images, the admin approves & publishes
- ⚙️ **Admin Panel** — manage posts (YouTube link or image upload), review suggestions, manage ad slots
- 📢 **6 Ad Slots** — top banner, left sidebar, right sidebar, video-size (16:9), in-feed native & footer banner
- 📱 **Mobile Friendly** — fully responsive on every screen size
- 🎨 **Bright & Branded** — custom design with gradients, animations and a premium look

## 🗂️ Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — hero, slider, feed, ads |
| `suggest.html` | Visitor content suggestion form |
| `admin.html` | Admin panel — posts, suggestions, ad slots |

## 🚀 Run Locally

```bash
python3 serve.py
# open http://localhost:8000
```

## 📢 Ad Slots

Paste your ad codes in **Admin → Ad Slots** (or use the defaults in `assets/js/data.js`). Slots: top, left, right, video (16:9), in-feed native, bottom. If an ad network does not fill a slot, a smartlink fallback banner is shown automatically.
